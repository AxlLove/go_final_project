# Планировщик задач

Веб-сервер с REST API, реализующий функциональность TODO-листа. Позволяет создавать, просматривать, редактировать и удалять задачи с поддержкой правил повторения.

## Выполненные задания со звёздочкой

- Порт сервера через переменную окружения `TODO_PORT`
- Путь к базе данных через переменную окружения `TODO_DBFILE`
- Правила повторения `w` (дни недели). `m` (дни месяца) пропущено
- Поиск задач по заголовку, комментарию и дате
- Аутентификация через JWT и переменную окружения `TODO_PASSWORD`
- Docker-образ

## Запуск локально

**Требования:** Go 1.21+

```bash
go run main.go
```

Сервер запустится на `http://localhost:7540`

**Переменные окружения:**

| Переменная | Описание | Значение по умолчанию |
|---|---|---|
| `TODO_PORT` | Порт сервера | `7540` |
| `TODO_DBFILE` | Путь к файлу базы данных | `scheduler.db` |
| `TODO_PASSWORD` | Пароль для входа (если не задан — аутентификация отключена) | пусто |

**Пример запуска с параметрами:**
```bash
TODO_PORT=8080 TODO_PASSWORD=secret go run main.go
```

## Запуск тестов

Перед запуском тестов убедитесь что сервер запущен.

```bash
go test -run ^TestApp$ ./tests       # проверка раздачи статики
go test -run ^TestDB$ ./tests        # проверка базы данных
go test -run ^TestNextDate$ ./tests  # проверка правил повторения
go test -run ^TestAddTask$ ./tests   # проверка добавления задачи
go test -run ^TestTasks$ ./tests     # проверка получения списка задач
go test -run ^TestTask$ ./tests      # проверка получения задачи
go test -run ^TestEditTask$ ./tests  # проверка редактирования задачи
go test ./tests                      # все тесты
```

**Настройки тестов** (`tests/settings.go`):

- `Port` — порт сервера (по умолчанию `7540`)
- `DBFile` — путь к файлу БД (по умолчанию `../scheduler.db`)
- `FullNextDate` — установить `true` для проверки правил `w` и `m`
- `Token` — JWT-токен для тестов с аутентификацией (получить через `/api/signin`)

Для тестов с аутентификацией запустите сервер с паролем, войдите через `http://localhost:7540/login.html`, скопируйте значение куки `token` и вставьте в `tests/settings.go`.

## Docker

**Сборка образа:**
```bash
docker build -t scheduler .
```

**Запуск контейнера:**
```bash
docker run -p 7540:7540 -v $(pwd)/data:/data scheduler
```

**Запуск с паролем:**
```bash
docker run -p 7540:7540 -v $(pwd)/data:/data -e TODO_PASSWORD=secret scheduler
```

База данных сохраняется в папку `data/` в текущей директории на хосте.

После запуска откройте `http://localhost:7540` в браузере.
